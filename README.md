# AdventureWorks Sales Analytics Dashboard

## Overview

This is an interactive Power BI dashboard built using the AdventureWorks dataset to analyze sales, revenue, profit, products, customers, and geographic performance.

I focused on making the report easy to navigate and interactive while keeping the visuals clean and simple.

## What I Worked On

* Updated the KPI cards to improve the overall look and presentation
* Added **Field Parameters** for dynamic analysis
* Created an interactive **slicer panel**
* Added working **navigation buttons**
* Improved the overall report layout and user experience
* Added interactive filtering across the report

## Analysis

The report looks at:

* Sales and revenue
* Profit and profitability
* Product performance
* Customer performance
* Geographic performance
* Sales trends over time
