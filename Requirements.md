# AdventureWorks Sales Analytics – Requirements

## Project Overview

The goal of this project is to build an interactive Power BI dashboard using the AdventureWorks dataset. The report should make it easy for users to understand sales performance and explore customer, product, and geographic information.

## What the Report Should Help Answer

The report should help answer questions such as:

* How are overall sales performing?
* Which products are selling the most?
* Which customers generate the most sales?
* Which locations have the highest sales?
* How does sales performance change over time?
* Which products or areas may need more attention?
* Where are the biggest opportunities for improvement?

## Dashboard Requirements

### Executive Dashboard

The Executive Dashboard should give users a quick overview of the business.

It should show the most important sales numbers and provide clear visuals that help users understand overall performance and trends.

Users should be able to use filters to look at the information from different perspectives.

### Customer Detail

The Customer Detail page should help users understand customer performance.

It should make it easy to see:

* Which customers generate the most sales.
* Customer purchasing activity.
* Differences in customer performance.
* Customer information by location.

Users should be able to filter the data and focus on specific customers when needed.

### Product Detail

The Product Detail page should focus on product performance.

It should help users identify:

* Best-selling products.
* Products with lower sales.
* Product categories and subcategories.
* Sales differences between products.
* Product performance over time.

### Map

The Map page should provide a visual view of sales by location.

It should help users quickly identify areas with strong or weak sales performance and understand how sales are distributed geographically.

## Key Metrics

The report should include important business metrics available in the dataset, such as:

* Total Sales
* Total Orders
* Total Quantity Sold
* Number of Customers
* Number of Products
* Average Order Value

Additional measures can be included when they provide useful business insights.

## Filters and Interaction

The report should be interactive so users can:

* Filter the data.
* Select specific products or customers.
* Explore different locations.
* Compare different categories.
* Move between report pages.
* Interact with charts and other visuals.

## Data Requirements

The report should use the AdventureWorks data and make sure the information is accurate and consistent.

The data should be properly connected so that sales, customers, products, dates, and locations can be analyzed together.

## Design Requirements

The report should have a clean and professional appearance.

Visuals should be easy to understand, with clear titles, labels, and consistent formatting. The dashboard should focus on useful information rather than unnecessary visuals.

## Expected Result

The final report should give users a simple way to understand AdventureWorks sales performance and explore the business from different perspectives.

The dashboard should turn the raw data into useful insights that can support better business decisions.

## Project Deliverables

The project should include:

* Power BI report
* Executive Dashboard
* Customer Detail page
* Product Detail page
* Geographic/Map analysis
* Requirements documentation
* README documentation
* Screenshots of the report
